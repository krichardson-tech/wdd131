Personal Library Site Project Plan

Kali Richardson

WDD 131

Overview

Purpose

This project is a personal library website that will hold the books you currently own, in the physical or digital place, and allow you to add more book over time. It will have two pages.

Audience

For anyone who loves books, organization, and can use a digital device.

Dynamic elements

One page will have a search bar where the user can search for a book thorught the title, author, or description. The second page will allow you to add a page with its corresponding information.

Wireframes

Below are the wireframes for my project.

Landing page

This page is where users will initially start. It will show a random book or few you have in your library and a search bar so you can search for specific books in your library.

Addition Page

This page will allow you to add another book to your library with its relevant information.

Extra Ideas

If I have time, I may also add something that will allow you to move a book to an "read but don't owned" section of the site. If I persue this further, I can also add filters that will sort the books too, either by author, genre, rating, etc.
